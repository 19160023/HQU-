## 二、怎么运行（对方视角）

1. 解压到一个**不含中文和空格**的路径，例如 `D:\campus-events`
2. 确认装了 **Node.js 22.5 或更高版本**（`node -v` 检查）
3. 双击 `启动.bat`，或在该目录执行：
   ```bash
   node server/server.mjs 8080
   ```
4. 浏览器打开 <http://localhost:8080>

首次启动会自动建库、建表、灌入 17 条示例活动和 6 条示例留言，控制台会打印演示账号（`admin / admin2026` 等）。

**没有 `npm install`，没有任何第三方依赖。** 数据库是 Node 内置的 `node:sqlite`，密码学用内置 `crypto`，HTTP 服务用标准库 `node:http` 手写。
